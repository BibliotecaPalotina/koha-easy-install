Manual Completo de Instalação e Configuração do Koha

Guia estruturado com foco em estabilidade operacional: preparação minuciosa do sistema operacional em 5 cenários e utilização do novo Koha Easy Install (Painel Interativo) para automação, backups em nuvem, restauração e publicação via Cloudflare Tunnel.

1. O que é e como funciona o Koha

O Koha é o sistema integrado de gestão de bibliotecas (ILS) de código aberto mais utilizado no mundo. Ele opera sobre a stack LAMP (Linux, Apache, MariaDB e Perl), funcionando como um servidor central corporativo.

Acesso Universal por Navegador

O sistema fica hospedado em uma única máquina servidora. Funcionários e leitores utilizam o Koha diretamente pelo navegador web (Google Chrome, Firefox, Edge), sem necessidade de instalar programas nos computadores de atendimento ou consulta.

O Koha opera obrigatoriamente através de duas portas de rede padronizadas:

  • Porta 8080 (Staff / Interface Administrativa): Painel restrito dos bibliotecários e atendentes. Utilizada para catalogação bibliográfica no padrão MARC21, controle de circulação (empréstimos e devoluções), cadastro de usuários, gestão de multas e geração de relatórios SQL.
  • Porta 80 (OPAC / Catálogo Público): Página pública voltada aos leitores. Permite consultar o acervo da biblioteca, checar disponibilidade nas estantes, renovar prazos e reservar títulos pela internet.

Gestão de Redes de Bibliotecas: Uma única instalação permite administrar múltiplas unidades físicas (como uma biblioteca central e várias filiais de bairros ou salas de leitura escolares). Todas compartilham o mesmo catálogo, mantendo o controle de estoque e regras de circulação individualizados.

2. Escolhendo a Hospedagem e Preparando o Sistema Operacional

O Koha foi concebido nativamente para rodar sobre Linux (Debian ou Ubuntu). A forma como você chega à linha de comando depende exclusivamente do método de instalação escolhido abaixo. Siga rigorosamente apenas o cenário que você escolheu:

Cenário 1: Servidor Físico Dedicado (Ubuntu Server)

Instalação limpa em um computador físico da biblioteca sem sistema operacional prévio.

  • Download da Imagem ISO: Baixe a imagem oficial do Ubuntu Server LTS.
  • Criação do Pendrive Bootável: Baixe e instale o BalenaEtcher. Conecte um pendrive de no mínimo 4GB, abra o BalenaEtcher, clique em Flash from file, selecione o arquivo ISO baixado, selecione seu pendrive e clique em Flash!.
  • Ajustes na BIOS da Placa-Mãe: Conecte o computador via cabo de rede no roteador. Ligue o PC pressionando a tecla de acesso à BIOS (Del, F2, F10 ou F12) e configure:
    • Secure Boot: Mude para Disabled.
    • SATA Mode: Garanta que esteja em AHCI (se a placa mãe tiver essa opção).
    • Restore on AC Power Loss / AC Back: Mude para Power On (faz o servidor ligar sozinho se a luz cair e voltar).
    • Fast Boot: Mude para Disabled.
    • Halt On: Mude para No Errors (impede que a BIOS trave o boot por falta de teclado conectado).
  • Instalação do Ubuntu Server: Na aba de boot da BIOS, selecione o pendrive. Durante o instalador:
    • Selecione o idioma e deixe a rede em DHCP automático (via cabo).
    • Particionamento: Escolha Use an entire disk (usar o disco inteiro).
    • Defina o nome do servidor, o nome de usuário e uma senha forte (anote esses dados!).
    • Atenção Crítica: Na tela de pacotes adicionais, marque com a barra de espaço a opção Install OpenSSH server. Sem isso, você não conseguirá acessar a máquina remotamente.
  • Ao terminar, reinicie a máquina, retire o pendrive e faça login com seu usuário e senha. Identifique o IP da máquina com o comando ip a (conforme explicado na Seção 3). Como esta máquina não tem interface gráfica, todo o gerenciamento será feito via SSH pelo PowerShell do seu computador de mesa.

Cenário 2: Servidor em Nuvem / VPS

Instalação em um provedor de nuvem (DigitalOcean, Hetzner, AWS, Hostinger, etc.).

  • Crie uma conta na empresa escolhida e acerte o método de pagamento.
  • Clique em Create Instance (ou Create Droplet).
  • Sistema Operacional: Escolha Ubuntu Server (versão LTS recente: 22.04 ou 24.04).
  • Plano de Hardware (Obrigatório): Selecione um plano que ofereça no mínimo 4GB de RAM e 2 vCPUs. Planos com 1GB ou 2GB travarão durante a indexação de buscas.
  • Autenticação: Escolha autenticação por senha root ou adicione sua chave SSH pública.
  • Finalize a criação. Em poucos segundos o painel da VPS fornecerá um Endereço de IP público e o usuário de login (normalmente root ou ubuntu). O acesso será feito remotamente a partir do seu terminal ou PowerShell via SSH.

Cenário 3: Computador com Linux Gráfico (Linux Mint ou Ubuntu Desktop)

Instalação em uma máquina com área de trabalho visual para uso direto no computador.

  • Download da ISO:
    • Opção 1 (Recomendada para iniciantes): Download Linux Mint (Cinnamon Edition).
    • Opção 2: Download Ubuntu Desktop.
  • Grave a ISO no pendrive utilizando o BalenaEtcher da mesma forma explicada no Cenário 1.
  • Desative o Secure Boot na BIOS do computador e inicie o sistema pelo pendrive.
  • Na área de trabalho do instalador, dê dois cliques no ícone "Install Linux Mint" (ou Install Ubuntu). O assistente é totalmente visual em português: escolha seu fuso horário, layout do teclado, crie seu nome de usuário e senha.
  • Conclua a instalação e reinicie o PC.
  • Vantagem Operacional deste Cenário: Você NÃO precisa usar SSH! Abra o terminal nativo do sistema pressionando as teclas Ctrl + Alt + T e execute os comandos diretamente nele.

Cenário 4: Windows usando VirtualBox

Execução do Ubuntu Server dentro de uma máquina virtual no Windows.

  • Ativação de Virtualização: Reinicie o Windows, entre na BIOS e ative o suporte a virtualização: procure por Intel Virtualization Technology (VT-x) ou SVM Mode (AMD) e marque como Enabled. Sem isso, o VirtualBox não criará sistemas de 64 bits.
  • Downloads Necessários: Baixe e instale o VirtualBox e baixe a ISO do Ubuntu Server LTS.
  • Criação da Máquina Virtual no VirtualBox:
    • Abra o VirtualBox e clique no botão Novo (New). Nome: Digite Koha-Server.
    • Imagem ISO: Aponte para o arquivo ISO do Ubuntu Server.
    • ATENÇÃO CRÍTICA: Na tela de criação, marque a caixa "Pular Instalação Desatendida" (Skip Unattended Installation). Se você permitir a instalação desatendida, o VirtualBox criará um usuário aleatório e ignorará o OpenSSH, trancando você fora do sistema!
  • Recursos de Hardware: Memória Base (RAM): no mínimo 4096 MB (4 GB). Processadores: aloque ao menos 2 CPUs. Disco Rígido: pelo menos 25 GB.
  • Configuração de Rede (Crucial para funcionar na rede local):
    • Vá em Configurações > Rede.
    • No campo Conectado a:, troque de "NAT" para Placa em modo Bridge (Bridged Adapter).
    • No campo Nome, selecione a placa de rede do seu computador (Wi-Fi ou Ethernet).
    • Por que isso é obrigatório? No modo NAT, o Koha fica isolado. No modo Bridge, seu roteador atribui um IP real para a máquina virtual, permitindo que a rede local acesse o Koha nas portas 8080 e 80.
  • Inicie a VM e siga a instalação manual do Ubuntu Server normalmente, lembrando de marcar o pacote OpenSSH.

Cenário 5: Windows usando WSL2

A forma mais leve de rodar o kernel Linux integrado diretamente dentro do Windows 10 ou 11.

  • Ative a virtualização (VT-x / AMD-V) na BIOS da sua placa-mãe.
  • No menu Iniciar do Windows, pesquise por Ativar ou desativar recursos do Windows e marque: Subsistema do Windows para Linux e Plataforma de Máquina Virtual. Clique em OK e reinicie.
  • No menu Iniciar, procure por PowerShell, clique com o botão direito e selecione Executar como Administrador. Digite o comando abaixo e tecle Enter:
    PowerShell (Administrador)
    wsl --install -d Ubuntu
  • Aguarde o download e instalação. Ao reiniciar, a janela preta do Ubuntu abrirá solicitando que você crie um usuário e uma senha (anote esses dados).
  • Fixe o atalho do Ubuntu na barra de tarefas.
  • Vantagem Operacional deste Cenário: Você NÃO precisa de SSH! Basta abrir o atalho do Ubuntu e colar os comandos diretamente nele. Para que o Koha funcione na rede, basta manter essa janela aberta minimizada.

3. Identificação de IP e Acesso ao Terminal

Quem precisa e quem NÃO precisa de SSH?

Cenários 3 e 5 (Linux Gráfico / WSL2): Você está trabalhando diretamente na máquina. NÃO precisa de SSH. Abra o terminal na sua tela (Ctrl + Alt + T no Linux ou atalho do Ubuntu no Windows) e execute todos os comandos por ele.

Cenários 1, 2 e 4 (Servidor Físico / VPS / VirtualBox): O servidor está rodando em modo texto sem monitor próprio ou em segundo plano. Você precisa conectar nele através do PowerShell de outro computador usando SSH.

Como identificar o IP do Servidor (Cenários 1, 2 e 4)

No terminal do Linux, execute o comando:

Terminal Linux
ip a

Como localizar seu IP na resposta: Procure pela interface de rede principal (ex: eth0, enp3s0 ou wlan0). Ignore a interface lo. Na linha que começa com inet, o número antes da barra é o seu IP (ex: se aparecer inet 192.168.1.50/24, o IP é 192.168.1.50). Se estiver em uma VPS, o IP é o endereço público fornecido pelo painel.

Conexão Remota via PowerShell (Apenas Cenários 1, 2 e 4)

No computador Windows que você usa para trabalhar, abra o PowerShell e digite o comando abaixo (substitua nomedousuario pelo nome do usuário que você criou no servidor e ipdoservidor pelo IP real que você descobriu):

PowerShell
ssh nomedousuario@ipdoservidor

Nota: Na primeira conexão, o PowerShell perguntará se você confia no servidor (Are you sure you want to continue connecting?). Digite yes e aperte Enter. Depois, digite sua senha (ela não aparece enquanto você digita).

4. Baixando e Iniciando o Painel Interativo (Koha Easy Install)

Esqueça scripts confusos. O novo sistema utiliza uma suíte de gerenciamento completa e interativa. Com o terminal aberto (seja local ou via SSH), execute o bloco de comandos abaixo para baixar o instalador de forma segura, dar permissões e abrir o painel:

Terminal Linux
sudo curl -fsSL "https://raw.githubusercontent.com/BibliotecaPalotina/koha-easy-install/refs/heads/main/installer" -o /usr/local/bin/options.sh
sudo chmod +x /usr/local/bin/options.sh
sudo options.sh

A partir de agora, sempre que você precisar gerenciar o Koha, atualizar o sistema, fazer backups ou alterar configurações, basta digitar sudo options.sh no terminal.

A Instalação do Servidor

Com o painel aberto na tela azul interativa, navegue com as setas do teclado, selecione a Opção 1 - Instalar o servidor Koha e pressione Enter. O sistema fará todo o trabalho pesado (instalar MariaDB, Apache, Memcached, configurar UTF-8, criar memória Swap e configurar o Koha). Aguarde a finalização.

5. Concluindo o Web Installer no Navegador

Após a Opção 1 finalizar, o painel exibirá as suas credenciais de acesso provisórias. Elas também são salvas permanentemente no arquivo /root/credenciais_koha.txt do seu servidor.

Abra seu navegador web e acesse:

  • Cenários 1, 2 e 4 (Servidor Físico / VPS / VirtualBox): Digite http://ipdoservidor:8080 (exemplo: http://192.168.1.50:8080).
  • Cenários 3 e 5 (Linux Mint / WSL2): Digite diretamente http://localhost:8080.

Siga os passos exatamente nesta sequência:

  1. Etapa 1 de 9 (Login Provisório): Aparecerá a tela inicial. No campo Usuário digite koha_library. No campo Senha, digite a senha gerada pelo painel (caso esqueça, acesse a Opção 2 no painel options.sh para vê-la novamente).
  2. Etapa 2 de 9 (Idioma): Selecione a opção Português do Brasil (pt-BR) e clique em Continuar.
  3. Etapa 3 de 9 (Módulos e Formato MARC): O assistente exibirá os módulos Perl (todos OK). Prossiga e escolha MARC21 (padrão internacional).
  4. Etapa 4 de 9 (Configurações Opcionais): Mantenha marcados os frameworks do MARC21, mas desmarque todas as caixas que mencionarem dados de exemplo ("amostras de usuários", "amostras de bibliotecas", "amostras de itens"). Isso impede que o banco seja criado com registros fictícios.
  5. Etapa 5 de 9 (Cadastro da Biblioteca): Código da Biblioteca: digite uma sigla curta (ex: BPM, CENTRAL). Nome da Biblioteca: o nome oficial completo.
  6. Etapa 6 de 9 (Categoria do Administrador): Código da Categoria: digite STAFF. Descrição: digite Administração. Tipo de Categoria: selecione Funcionário (Staff).
  7. Etapa 7 de 9 (Superlibrarian): Preencha os dados da conta de gerenciamento. Sobrenome/Nome: Seu nome. Número de Cartão: 1. Nome de Usuário: o login do dia a dia. Senha: Crie uma senha forte e segura e anote-a.
  8. Etapa 8 de 9 (Categoria de Exemplar): Código do Tipo de Exemplar: digite LIV. Descrição: digite Livro.
  9. Etapa 9 de 9 (Regras de Circulação): Total de empréstimos permitidos: 3 a 5 exemplares. Período de empréstimo: 14 dias. Renovações permitidas: 2 renovações.

6. Restauração de Backup (Pelo Painel)

Se você já possui um arquivo de banco de dados extraído de uma instalação anterior do Koha, é extremamente fácil restaurá-lo com a nova ferramenta de gestão.

1. Nome e Formato do Arquivo

O arquivo precisa ser um dump SQL descompactado (.sql) ou compactado (.sql.gz). Sugerimos nomear para algo simples, como backup.sql.gz.

2. Como colocar o arquivo no servidor em cada Cenário

Se você está no Linux Mint / Ubuntu Desktop (Cenário 3):

Abra o gerenciador de arquivos visual do Linux, vá na sua pasta pessoal (Home) e simplesmente cole o arquivo lá dentro.

Se você está no Windows usando WSL2 (Cenário 5):

Abra o Explorador de Arquivos do Windows e digite na barra de endereços (substitua nomedousuario pelo seu usuário do Ubuntu):

\\wsl$\Ubuntu\home\nomedousuario\

Cole o arquivo lá dentro.

Se você está no Servidor Físico, VPS ou VirtualBox (Cenários 1, 2 e 4):

Coloque o arquivo na raiz do disco C:\ do Windows (ficando C:\backup.sql.gz). Abra uma nova janela do PowerShell local e use o comando de transferência (SCP):

PowerShell (Local)
scp "C:\backup.sql.gz" nomedousuario@ipdoservidor:/home/nomedousuario/

3. Executando a Restauração Pelo Painel Interativo

No terminal do Linux, abra o painel de controle:

Terminal Linux
sudo options.sh
  1. Selecione a Opção 3 - Restaurar Acervo de um Backup.
  2. O sistema abrirá o Explorador de Arquivos interno. Navegue até a pasta onde você salvou o backup (geralmente ele inicia na sua pasta Home e você já verá o arquivo lá).
  3. Selecione o arquivo. O script fará uma validação de integridade para garantir que o backup não está corrompido, e recriará todo o banco de dados e os índices de busca automaticamente.

7. Backup em Nuvem Automatizado (Google Drive)

Uma das maiores novidades do novo painel é a integração nativa com nuvens via Rclone.

  1. Abra o painel com sudo options.sh.
  2. Selecione a Opção 10 - Configurar backup em nuvem.
  3. Escolha Modo Expresso (Google Drive).
  4. O painel fornecerá um comando no formato rclone authorize "drive" "...".
  5. Abra o terminal ou PowerShell do seu computador local (onde você tem navegador web), baixe o Rclone se não tiver, cole o comando gerado e aperte Enter.
  6. Seu navegador se abrirá solicitando login e autorização na conta do Google.
  7. Após autorizar, o terminal local retornará um grande código (token). Copie esse código inteiro.
  8. Volte ao terminal do servidor, cole o código e aperte Enter. O painel cuidará de criar as pastas na nuvem e agendar os envios diários no crontab.

8. Publicando o Koha na Internet (Cloudflare Tunnel Pelo Painel)

O Cloudflare Tunnel é a forma mais segura de expor o Koha para a internet. Ele dispensa abertura de portas no modem ou roteador, oculta o IP real e entrega certificado SSL (HTTPS) automático.

Passo 1: Domínio Institucional ou Subdomínio Gratuito

Para colocar o catálogo na web, é necessário um endereço de domínio:

  • Domínio Próprio (Recomendado): Registre um domínio (ex: bibliotecamunicipal.org) na Cloudflare.
  • Subdomínio Gratuito (Custo Zero): Utilize um subdomínio no DigitalPlat:
    1. Acesse domain.digitalplat.org e crie uma conta.
    2. Clique em Register a domain e selecione Domain registration.
    3. Digite o nome escolhido e escolha uma das extensões: .dpdns.org, .us.kg, .qzz.io ou .xx.kg.
    4. Na Cloudflare, clique em Adicionar um site, insira o domínio criado e escolha o Plano Gratuito (Free).
    5. A Cloudflare fornecerá dois servidores de nome autoritativos (ex: ns1.cloudflare.com e ns2.cloudflare.com).
    6. Volte ao DigitalPlat, cole os endereços nos campos Name Server 1 e Name Server 2 e salve.
    7. Na Cloudflare, clique em Atualizei meus nameservers e aguarde a propagação.

Passo 2: Criando o Túnel Cloudflare e Integrando com o Painel

  1. No painel lateral da Cloudflare, navegue até: Zero Trust > Networks > Tunnels.
  2. Clique em Add a tunnel, escolha Cloudflare Managed e defina um nome (ex: koha-servidor).
  3. Na tela de instalação do conector, a Cloudflare exibirá um comando gigante em um quadro preto. Copie esse comando inteiro (ou apenas o Token longo que começa com `ey...`).
  4. Abra o painel no seu servidor (sudo options.sh).
  5. Escolha a Opção 14 - Acesso externo (Cloudflare Tunnel).
  6. Cole o comando ou token na caixa de texto. O sistema baixará e instalará o serviço instantaneamente!

Passo 3: Mapeando as Rotas do Staff e do OPAC

No painel do túnel da Cloudflare, clique na aba Public Hostnames e adicione as duas rotas:

Finalidade Subdomínio Domínio Caminho (Path) Tipo (Service) URL Local
Staff (Administração) adm Seu domínio Em branco HTTP localhost:8080
OPAC (Público) Em branco Seu domínio Em branco HTTP localhost:80

Os bibliotecários acessarão por https://adm.seudominio.org e os leitores por https://seudominio.org.

Passo 4: Indexação no Google e URLs Base do Koha

  1. Acesse o Google Search Console, insira o endereço do seu OPAC e copie o código TXT de verificação.
  2. Na Cloudflare (em DNS > Registros), adicione um registro TXT com o Nome @ e o código do Google.
  3. No painel Staff do Koha (como administrador), acesse Administração do Koha > Preferências do Sistema:
    • OpacBaseUrl: Digite a URL HTTPS pública completa do catálogo (ex: https://seudominio.org).
    • StaffBaseUrl: Digite a URL HTTPS pública completa da administração (ex: https://adm.seudominio.org).
    • LibraryName: Insira o nome oficial da biblioteca.
    • OpacMetaRobots: Certifique-se de não bloquear robôs de busca.
